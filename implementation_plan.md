# Complete Game UI/UX Reconstruction Prompt

## Role

Act as a **senior UI/UX designer and game interface specialist** with extensive experience designing modern, polished, commercially viable game interfaces.

Your task is to **completely reconstruct the visual design and user experience of the game described or shown in the provided reference**, while preserving its core functionality, information architecture, and gameplay intent.

The final result should feel like a **professionally designed modern game**, with strong visual identity, excellent usability, and a clean interface that is visually engaging without becoming cluttered.

---

## Core Design Objective

Redesign the entire game interface from the ground up following modern **UI/UX, interaction design, visual hierarchy, accessibility, and game design principles**.

The interface should communicate:

* What the player can do
* What is currently happening
* What is most important
* What actions are available
* What the player's current status is
* What the consequences of each action are

The player should be able to understand the interface naturally without needing to study it.

Prioritize:

1. **Clarity**
2. **Visual hierarchy**
3. **Ease of navigation**
4. **Immersion**
5. **Consistency**
6. **Responsiveness**
7. **Visual polish**
8. **Minimal cognitive load**

Do not add unnecessary UI elements simply to make the interface look more complex.

---

# Visual Direction

Create a visual style that is:

* Modern
* Premium
* Attractive
* Immersive
* Minimal but expressive
* Clean
* Sophisticated
* Game-oriented
* Easy to understand at a glance

Avoid making the interface feel like a generic dashboard or productivity application.

The design should still feel like a **real game**, with personality and atmosphere.

Use visual depth through:

* Subtle gradients
* Soft shadows
* Layered surfaces
* Controlled glow effects
* Transparency where appropriate
* Subtle textures
* Carefully selected highlights
* Depth and elevation
* Strong typography hierarchy

Do not overuse effects.

Every visual effect must serve a purpose.

---

# UI/UX Principles

## Visual Hierarchy

Establish a clear hierarchy between:

* Primary information
* Secondary information
* Interactive elements
* Player status
* Game state
* Navigation
* Notifications
* Decorative elements

The most important information should immediately attract attention.

Avoid giving every element the same visual weight.

---

## Simplicity

Follow a **"less, but better"** approach.

Remove or simplify elements that do not contribute to:

* Gameplay
* Navigation
* Decision-making
* Player feedback
* Context

Do not fill empty space unnecessarily.

Negative space should be intentionally used to improve readability and visual balance.

---

## Consistency

Create a consistent design language across the entire game.

Maintain consistency in:

* Typography
* Colors
* Buttons
* Icons
* Cards
* Panels
* Spacing
* Border radius
* Shadows
* Interaction states
* Animations
* Feedback patterns

A component that performs the same function should look and behave the same everywhere.

---

# Design System

Create a coherent design system before designing the individual screens.

## Color System

Define:

* Primary color
* Secondary color
* Accent color
* Background colors
* Surface colors
* Border colors
* Text colors
* Success color
* Warning color
* Error color
* Information color

Use a restrained palette.

The accent color should be used strategically to guide the player's attention rather than appearing everywhere.

Ensure sufficient contrast between text and backgrounds.

---

## Typography

Use a modern, highly readable typeface appropriate for gaming.

Define:

* Display / hero typography
* Page titles
* Section titles
* Body text
* Labels
* Buttons
* Captions
* Numerical/statistical information

Use font weight and size to establish hierarchy rather than relying excessively on color.

Avoid using too many different fonts.

---

## Spacing

Use a consistent spacing system.

Maintain predictable spacing between:

* Sections
* Components
* Text
* Buttons
* Cards
* Navigation elements

Use whitespace deliberately to prevent visual fatigue.

---

## Components

Create reusable components for:

* Primary buttons
* Secondary buttons
* Icon buttons
* Cards
* Panels
* Navigation
* Tabs
* Progress bars
* Health/status bars
* Inventory elements
* Notifications
* Tooltips
* Modals
* Dialogs
* Dropdowns
* Toggles
* Sliders
* Player statistics
* Game-state indicators

Each component should have clear:

* Default state
* Hover state
* Pressed state
* Focus state
* Disabled state
* Selected state
* Error state when applicable

---

# Game Screens

Reconstruct the complete game experience, not just the main screen.

Consider and redesign all relevant screens, including:

## Main Menu

Create a strong first impression.

Include only the most important actions, such as:

* Continue
* New Game
* Multiplayer
* Settings
* Profile
* Exit

Adapt the actual options to the game.

The main menu should immediately communicate the game's identity.

---

## Gameplay Interface

Design the HUD around the player's actual needs.

Prioritize:

* Player status
* Objectives
* Important resources
* Current score
* Game state
* Essential controls

Keep the HUD unobtrusive.

The player should remain focused on the gameplay rather than the interface.

---

## Pause Menu

Create a lightweight pause experience.

Possible actions:

* Resume
* Restart
* Settings
* Controls
* Exit

Avoid turning the pause menu into a full dashboard.

---

## Results / End-of-Game Screen

Clearly communicate the outcome.

Show:

* Result
* Score
* Progress
* Rewards
* Statistics
* Achievements when relevant
* Next action

Make the primary next step visually obvious.

---

## Settings

Organize settings into logical categories.

For example:

* Gameplay
* Controls
* Audio
* Graphics
* Accessibility
* Language
* Account

Avoid presenting a huge wall of options.

Use progressive disclosure when necessary.

---

## Profile / Progression

If the game contains progression, present it clearly through:

* Level
* XP
* Achievements
* Statistics
* Unlocks
* Currency
* Customization

Avoid excessive gamification elements that do not contribute meaningful information.

---

# Responsive Design

Design the interface so it can adapt intelligently to different screen sizes.

Consider:

* Desktop
* Laptop
* Tablet
* Mobile when relevant
* Different aspect ratios
* Ultrawide displays

Do not simply scale the desktop interface down.

Reorganize elements when necessary.

Important information must remain accessible at smaller resolutions.

---

# Interaction Design

Every interactive element should provide clear feedback.

Use subtle:

* Hover animations
* Press animations
* Transitions
* Selection states
* Loading states
* Success feedback
* Error feedback

Animations should feel:

* Fast
* Smooth
* Intentional
* Responsive

Avoid excessive animations.

The interface should never feel slow because of decorative transitions.

---

# Accessibility

Follow modern accessibility principles.

Ensure:

* Adequate color contrast
* Readable typography
* Clear focus states
* Distinguishable interactive elements
* Icons are not the only source of meaning
* Important information is not communicated through color alone
* Controls are large enough to interact with comfortably
* Text remains readable over backgrounds

Where appropriate, provide options for:

* Text scaling
* Colorblind-friendly palettes
* Reduced motion
* Subtitles
* Control remapping

---

# Information Architecture

Before creating screens, analyze the game's information architecture.

Determine:

* What information belongs together
* What actions are primary
* What actions are secondary
* Which screens should be accessible directly
* Which information should be hidden until needed
* Which interactions should be contextual

Reduce unnecessary navigation steps.

The player should reach frequently used functionality quickly.

---

# Composition

Use strong composition principles:

* Alignment
* Balance
* Contrast
* Rhythm
* Proximity
* Repetition
* Scale
* Negative space

Avoid placing UI elements randomly around the screen.

Create a deliberate visual flow that guides the player's eyes naturally.

---

# Depth and Atmosphere

Use the game's world, theme, or narrative to influence the interface.

UI should feel like it belongs to the game.

However, prioritize usability over thematic decoration.

For example:

* A futuristic game may use subtle holographic elements.
* A fantasy game may use restrained ornamental details.
* A horror game may use atmospheric contrast and restrained distortion.
* A sci-fi game may use technical typography and controlled lighting.

Do not allow the theme to compromise readability.

---

# Avoid These Problems

Do **not** create:

* Excessive gradients
* Excessive glow
* Too many colors
* Excessive glassmorphism
* Huge amounts of text
* Unnecessary cards
* Oversized buttons
* Excessive borders
* Random decorative elements
* Cluttered HUDs
* Inconsistent icons
* Excessive animations
* Tiny unreadable text
* Poor contrast
* Generic dashboard layouts
* Interfaces that look like templates

The result should feel **intentional rather than decorated**.

---

# Premium Game Feel

The final design should feel comparable to a professionally produced commercial game.

Focus on small details that increase perceived quality:

* Precise spacing
* Consistent alignment
* Strong typography
* Refined icons
* Smooth transitions
* Clear interaction feedback
* Consistent component behavior
* Thoughtful empty states
* Polished loading states
* Clear error states
* Appropriate visual emphasis

The goal is not to make the interface visually complicated.

The goal is to make it **feel expensive, intentional, and polished**.

---

# Design Process

Follow this process:

### Step 1 — Analyze

Analyze the provided game/reference and identify:

* Core gameplay
* Main user flows
* Existing screens
* Existing UI problems
* Important information
* Primary actions
* Secondary actions
* Visual identity
* Opportunities for improvement

### Step 2 — Define the Design Language

Establish:

* Color palette
* Typography
* Spacing system
* Component style
* Iconography
* Shadows
* Borders
* Radius
* Motion principles

### Step 3 — Create the Information Architecture

Define the navigation and hierarchy between screens.

### Step 4 — Design the Core Screens

Start with:

1. Main menu
2. Gameplay HUD
3. Pause menu
4. Results screen
5. Settings
6. Profile/progression

Then create any additional screens required by the game.

### Step 5 — Create Reusable Components

Ensure recurring elements are represented as consistent components rather than individually designed objects.

### Step 6 — Refine

Review every screen for:

* Clarity
* Consistency
* Accessibility
* Spacing
* Visual hierarchy
* Responsiveness
* Cognitive load
* Game atmosphere

Remove anything unnecessary.

---

# Final Design Rule

**Do not confuse visual complexity with visual quality.**

A successful redesign should make the game look more attractive while simultaneously making it easier to understand and use.

Every element should have a reason to exist.

Every interaction should feel intentional.

Every screen should have a clear visual hierarchy.

The final result should communicate:

> **Modern. Immersive. Clean. Playable. Premium.**

Reconstruct the entire game interface according to these principles while preserving the game's fundamental identity and functionality.
